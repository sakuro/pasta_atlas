개인정보 처리방침

수집하는 정보

OAuth(, , )로 로그인할 때 각 제공자로부터 다음 정보를 수신합니다:

  • 해당 제공자에서의 계정을 식별하는 고유 ID
  • 해당 제공자에서의 사용자 이름(의 사용자 이름 후보로 사용)
  • 프로필 사진 URL(아바타 후보로 사용)

서비스 이용 중 제공하는 정보도 저장합니다:

  • 업로드한 지도 타일 이미지 및 메타데이터( 출력물) — 맵 이름, 세이브 이름, 맵 시드, 맵 교환 문자열, 설치된 MOD, 게임 버전, 플레이 틱 수 포함
  • 설정한 아바타 이미지
  • 표시 이름, 시간대, 언어 설정

서버는 접근 로그(IP 주소, 요청 메서드와 경로, 상태 코드, 요청 크기, 처리 시간, 시각)도 기록합니다. 요청 경로에는 사용자 이름이나 지도 식별자가 포함될 수 있습니다. 접근 로그는 30일간 보관하며 서비스 운영과 부정 이용 조사에만 사용합니다.

정보 이용 목적

수집한 정보는 서비스 제공 목적으로만 사용합니다:

  • 본인 확인 및 로그인 상태 유지
  • 업로드한 지도 표시 및 공유
  • 다른 사용자에게 프로필 표시

업로드한 지도와 프로필은 로그인하지 않은 방문자를 포함해 누구나 볼 수 있습니다.

서비스 운영에 필요한 경우를 제외하고 개인정보를 제3자에게 판매하거나 공유하지 않습니다(아래 데이터 저장 참조).

쿠키

로그인 상태를 유지하기 위해 쿠키(pasta_atlas.session) 하나를 사용합니다. 유효 기간은 1년입니다. 가입 도중에는 가입을 완료할 때까지 OAuth 제공자에게서 받은 식별자, 사용자 이름, 프로필 이미지 URL도 이 쿠키에 일시적으로 보관합니다. 추적, 광고, 분석 목적의 쿠키는 사용하지 않습니다.

데이터 저장

지도 이미지와 아바타는 Amazon S3에 저장되며 Amazon CloudFront를 통해 제공됩니다. 계정 정보, 지도 메타데이터, 설정 정보는 Amazon RDS for PostgreSQL에, 애플리케이션 로그는 Amazon CloudWatch Logs에 저장됩니다. 데이터는 AWS 아시아 태평양(도쿄) 리전에 저장되며, CloudFront는 지도 이미지를 전 세계 엣지 로케이션에 캐시합니다. Amazon Web Services 외의 제3자는 데이터에 접근할 수 없습니다.

데이터 보존

  • 지도 및 관련 데이터는 삭제하거나 계정을 탈퇴할 때까지 보존됩니다.
  • 지도 또는 계정을 삭제하면 즉시 표시되지 않으며, 관련 파일(지도 이미지와 아바타)은 이후 백그라운드에서 저장소에서 삭제됩니다.
  • 데이터베이스 자동 백업은 7일간 보관되므로, 데이터베이스에서 삭제된 정보는 최대 그 기간 동안 백업에 남을 수 있습니다.
